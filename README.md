## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/File%20Folder.png" width="35" height="35" /> Mimari Klasör & Dosya Yapısı

Proje, gereksiz şişkinliklerden arındırılmış, modüler ve yüksek performanslı bir **Single Page Application (SPA)** dosya düzenine sahiptir:

```bash
📦 samet-colak.github.io
 ┣ 📂 assets
 ┃ ┗ 📜 favicon.svg          # Vektörel sekme ikonu ve marka simgesi
 ┣ 📂 css
 ┃ ┣ 📜 style.css             # Genel değişkenler, tipografi, navbar & footer stilleri
 ┃ ┣ 📜 home.css              # Hero karşılama alanı ve buton efektleri
 ┃ ┣ 📜 about.css             # Hakkımda bölümü ve biyografi düzeni
 ┃ ┣ 📜 projects.css          # Proje kartları, LED çipleri ve yeni modal penceresi
 ┃ ┣ 📜 certificates.css      # Sertifikalar ve başarı ızgarası
 ┃ ┣ 📜 contact.css           # İletişim formu ve sosyal bağlantı kartları
 ┃ ┗ 📜 404.css               # Siber hata sayfası ve Snake.exe stilleri
 ┣ 📂 js
 ┃ ┣ 📜 three.min.js          # Optimize Three.js 3D kütüphanesi
 ┃ ┣ 📜 three-scene.js        # 3D arka plan parçacık ve kozmik küre sahnesi
 ┃ ┣ 📜 script.js             # Global çekirdek, dil değiştirici (TR/EN) & modal kontrolü
 ┃ ┣ 📜 home.js               # Ana sayfa dinamik yazı ve karşılama animasyonları
 ┃ ┣ 📜 about.js              # Hakkımda bölümü dinamik sayaçları
 ┃ ┣ 📜 projects.js           # Proje filtreleme ve etkileşim motoru
 ┃ ┣ 📜 contact.js            # İletişim formu doğrulama ve geri bildirim sistemi
 ┃ ┗ 📜 404.js                # Snake.exe oyun motoru & Web Audio ses sentezi
 ┣ 📜 index.html              # Ana SPA platformu (SEO, Open Graph ve Twitter Cards hazır)
 ┣ 📜 404.html                # Özel hata sayfası & Snake.exe Easter Egg
 ┣ 📜 CNAME                   # sametcolak.com.tr özel alan adı yönlendirmesi
 ┣ 📜 .nojekyll               # Jekyll derlemesini atlayarak hızlı dağıtım sağlayan bayrak
 ┣ 📜 sitemap.xml             # Google indeksleme ve arama motoru haritası
 ┣ 📜 robots.txt              # Arama motoru tarayıcı izinleri
 ┣ 📜 humans.txt              # Proje mimarı ve geliştirici künyesi
 ┗ 📜 README.md               # Proje vitrini ve dokümantasyonu
```

## <img src="https://raw.githubusercontent.com/Tarikul-Islam-Anik/Animated-Fluent-Emojis/master/Emojis/Objects/Laptop.png" width="35" height="35" /> Yerel Geliştirme & Çalıştırma

Projeyi bilgisayarınızda anında çalıştırmak için:

1. Depoyu yerel ortamınıza klonlayın veya zip olarak indirin:
   ```bash
   git clone https://github.com/samet-colak/samet-colak.github.io.git
   ```
2. Proje dizinine gidin:
   ```bash
   cd samet-colak.github.io
   ```
3. Herhangi bir yerel HTTP sunucusu başlatın:
   - **Python ile:** `python -m http.server 8000` *(veya `run_server.bat` dosyasına çift tıklayın)*
   - **VS Code ile:** Live Server eklentisini kullanarak `index.html` dosyasını açın.
4. Tarayıcınızda `http://localhost:8000` adresine gidin.
