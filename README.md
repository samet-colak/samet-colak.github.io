## 🎯 Proje Vizyonu & Felsefesi

**[sametcolak.com.tr](https://sametcolak.com.tr)**, sıradan portfolyo şablonlarının ötesine geçerek; **Apple, Linear ve Vercel** gibi dünya standartlarındaki teknoloji şirketlerinin tasarım kültürünü yansıtan, yeni nesil bir dijital mühendislik platformudur.

### 💡 Temel Tasarım İlkeleri:
1. **Saf & Bağımsız (Zero-Dependency):** React, Vue veya Bootstrap gibi devasa kütüphanelere bağımlı olmadan, yalnızca saf **HTML5, Modern CSS3 ve Vanilla JavaScript (ES6+)** ile sıfırdan inşa edilmiştir.
2. **Sinematik 3D Derinlik:** Three.js ile geliştirilen GPU hızlandırmalı WebGL parçacık alanı, donanımı zorlamadan stabil 60 FPS akıcılık sağlar.
3. **Porselen Cam Estetiği (Glassmorphism):** Yüksek kaliteli `backdrop-filter`, çok katmanlı ışık kırılımları ve pürüzsüz mikro-etkileşimler.
4. **Sıfır FOUC (Anti-Flash) Tema Motoru:** Koyu ve açık tema arasında geçiş yaparken beyaz/siyah patlama olmadan pürüzsüz geçiş ve tarayıcı hafızası (`localStorage`).

## 🚀 Yerel Geliştirme Ortamı

Projeyi kendi bilgisayarınızda klonlayıp incelemek veya çalıştırmak için:

1. **Depoyu Klonlayın:**
   ```bash
   git clone https://github.com/samet-colak/samet-colak.github.io.git
   ```
2. **Proje Dizinine Girin:**
   ```bash
   cd samet-colak.github.io
   ```
3. **Yerel Sunucuyu Başlatın:**
   - **Python ile:**
     ```bash
     python -m http.server 8000
     ```
   - **Node.js (npx) ile:**
     ```bash
     npx serve .
     ```
   - **VS Code:** `Live Server` eklentisiyle `index.html`'e sağ tıklayıp *"Open with Live Server"* deyin.
4. **Tarayıcıda Açın:**
   Tarayıcınızda `http://localhost:8000` adresine gidin.
